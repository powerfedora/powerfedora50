# PowerFedora50

50 只优质股池的本地研究系统。**只在股池里选股**：看板、指数、晨报都按股池计算，提醒和交易日志拒绝池外的股票。

零依赖（只用 Node 自带模块），数据存成 JSON 文件，装好 Node 就能跑。

## 功能

| 页面 | 内容 |
|---|---|
| 看板 | 大盘指数；大盘分时图上的**财联社全市场题材锚点**（如白酒、证券、人形机器人）；**股池等权指数** K 线 + 5/10/20/60/120/250 日均线 + 均线排列/短中长期位置/支撑压力判断；行情与技术点位表（可排序、筛选）；股池新闻。点任意股票弹出 K 线（均线、成交额、MACD）、点位、对标美股、新闻 |
| 板块指数 | 当前股池分类对应的东方财富行业指数；沿用个股技术指标列，展示成分 A 股总市值前三的龙头股与当日领涨股，可搜索、筛选、排序；数据缺失会明确提示 |
| 晨报 | 每天自动生成：隔夜美股大盘、每只股池股票的对标美股涨跌、前一天 8:00 到现在的个股新闻、股池指数位置。可翻历史、手动生成、下载 Markdown |
| 股池管理 | 增删股票、改板块、维护对标美股。新增时用行情校验代码；增删后指数立即重算 |
| 提醒 | 价格涨到/跌到、当日涨跌幅、站上/跌破均线。按"穿越"触发，不会反复响；支持页面提示、浏览器通知、macOS 系统通知 |
| 交易日志 | 记买卖和理由；自动算持仓成本（移动加权平均，含手续费）、已实现/未实现盈亏、胜率、盈亏比；每笔平仓可写复盘笔记 |
| 设置 | 晨报时间、刷新间隔、指数基点等 |

页面通过 SSE 接收服务端推送：行情一更新，看板自动刷新，不用手动点。

## 运行

需要 Node 20 以上（`node -v` 检查）。

```bash
git clone <本仓库>  &&  cd PowerFedora50
npm start                 # 连接东方财富，真实数据
# 打开 http://127.0.0.1:5050
```

- `npm run demo`：用模拟数据启动（不联网，页面顶部有"模拟数据"提示），用来熟悉界面。数据存在 `data/mock/`，和真实数据分开。
- `npm test`：运行测试。
- 端口、数据目录：`PORT=8080 POWERFEDORA_DATA=/path npm start`。

第一次启动会下载 49 只股票约 3 年的日线（十几秒），之后每天只增量更新。

### 开机自启（Mac）

晨报靠服务常驻来准点生成。让它登录后自动运行：

```bash
bash scripts/install-launchd.sh        # 安装
bash scripts/install-launchd.sh remove # 卸载
```

电脑 8:00 时睡眠或关机的话，开机后服务会**补生成**当天晨报（晨报里会注明"补生成"）。

## 数据与调度

- 行情：东方财富公开接口。交易时段（9:15–11:32、13:00–15:02）每 20 秒刷新，其余时间每 10 分钟；日线每天首次启动和收盘后（15:10）各更新一次；美股每 10 分钟；新闻每 15 分钟。大盘分时的全市场题材锚点每 15 秒从财联社看盘页面刷新；若暂时不可用，图上回退为股池板块异动。间隔都可在设置里改。
- 对标美股：每只股池股票对应一只业务最接近的美股（初始表来自项目文档《股池规则》），在「股池管理」里可改。美股所属交易所（纳斯达克/纽交所/Arca）自动识别并缓存。
- 股池等权指数：每天按成分股平均涨跌幅链式推算，默认 2024-09-02 = 1000 点；停牌或未上市的股票当天不计入；日内高低点用成分股高低点的平均近似。
- 数据目录 `data/`（已在 .gitignore）：`pool.json` 股池、`alerts.json` 提醒、`journal.json` 交易日志、`reports/` 历史晨报、`kline/` 日线缓存、`settings.json`。**备份就拷这个目录。**

## 安全说明

- 系统没有登录功能，默认只监听 `127.0.0.1`（本机）；接口会拒绝其他网站发来的跨站请求。**不要把它直接暴露到公网**；要远程用，请放在 VPN / 反向代理 + 认证后面。
- 新闻标题一律按纯文本渲染，链接只放行 eastmoney.com 域名。

## 说明

技术点位是均线和高低点的计算结果，晨报和复盘统计由系统自动整理，仅供复盘参考，不构成投资建议。东方财富接口如有调整，改 `src/em.js` 即可。

### 板块指数数据

访问 `http://127.0.0.1:5051/#/sectors`（默认端口运行时将 5051 换为 5050）。合并的股池分类展开为实际行业指数，映射保存在 `src/sectors.js`。龙头股定义为行情源板块成分 A 股总市值前三，与当日领涨股分列。板块行情缓存 1 分钟，龙头成分缓存 10 分钟；真实日线及结果缓存在 `data/sectors/`。行情获取失败时保留缓存并标明，日线不可用时技术指标显示“—”，不以股池个股数据代替全市场指数。板块同时间成交额和对标美股尚无数据，显示“—”。

板块指数列表下方的“板块轮动”显示最近 10 个有效交易日的 RS20 排名：上半区最高 10 位，下半区最低 10 位。历史数据使用当前关注板块与沪深300在相同交易日的日线回算，今日快照与列表保持一致。结果保存到 `data/sectors/rotation.json`，服务运行期间每分钟采集，即使页面未打开也会记录；缺少数据不生成虚假日期列。

### 股市情报站

访问 `#/intelligence`。服务运行期间每 20 秒读取金十首页“市场快讯”相同的公开接口（channel=-8200），按快讯 ID 去重，保存最近 500 条至 `data/intelligence/jin10.json`。采集失败时保留缓存、显示错误并在下一轮重试；标题链接到金十快讯原页。

情绪标签按标题措辞规则判断；板块按快讯文字关键词匹配，股票名单取实际板块成分与当前股池的交集，并补充文字中直接提及的股池公司。标签提示中显示判断依据，未匹配的新闻仍保留。股票按钮复用本地 K 线弹窗，支持同条新闻内的股票切换。页面支持情绪筛选、搜索和“只看涉及股池”。
